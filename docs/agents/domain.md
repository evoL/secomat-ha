# Domain Docs

## Before exploring

Read `GLOSSARY.md` and any relevant ADRs in `docs/adr/` (proceed silently if `docs/adr/` does not exist yet).

## Vocabulary

Use terms as defined in `GLOSSARY.md` and avoid the synonyms listed under `_Avoid_`. If a domain concept is missing from `GLOSSARY.md`, note the gap for `/domain-modeling` rather than inventing ad-hoc terminology.
