# Map `secomat_state` via an explicit cycle-state table rather than bitwise decoding

Although `payload.secomat_state` uses a 4-bit hardware nibble (`0x01` auxiliary/valve pre-charge, `0x02` circulation fan, `0x04` heat-pump compressor, `0x08` defrost/equalization mode), we map only the 7 verified composite values (`0` → `Idle`, `2` → `Fan only`, `5` → `Transition`, `6` → `Drying`, `10` → `Moisture check`, `12` → `Defrost`, `15` → `Complete`) via an explicit lookup table and report any other integer as unknown. The nibble is not an orthogonal bitmask: `0x08` changes meaning depending on whether it pairs with the fan (`10`) or the compressor (`12`), and `0x0F` (`15`) is a cycle-complete sentinel with all physical outputs off rather than all outputs running simultaneously.
